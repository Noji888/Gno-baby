# GNO BABY - ระบบตั้งชื่อเด็กตามวันเกิดและราศี

เว็บแอปพลิเคชัน Full-Stack สำหรับแนะนำชื่อเด็กภาษาไทยมงคลตามวัน เดือน ปีเกิด และราศี ด้วยศาสตร์ทักษาปกรณ์โบราณ พร้อมระบบสมาชิก Member ID และแผงควบคุมผู้ดูแลระบบ (Admin Dashboard)

---

## 🌟 ฟังก์ชันหลักของระบบ

1. **ระบบตั้งชื่อและคำนวณมงคลตามวันเกิด (ทักษาปกรณ์):**
   - รองรับการกรอกชื่อเล่นคุณพ่อ-คุณแม่
   - เพศของเด็ก: เด็กชาย, เด็กหญิง หรือทุกเพศ
   - วัน เดือน ปีเกิด (รองรับการคำนวณทั้ง พ.ศ. และ ค.ศ.)
   - เวลาเกิด (แยกการคำนวณวันพุธกลางวัน 06:00-17:59 น. และวันพุธกลางคืน 18:00-05:59 น.)
   - คำนวณราศีอัตโนมัติตามปฏิทินโหราศาสตร์ไทย 12 ราศี หรือเลือกเอง
   - คัดกรองอักษรขึ้นต้น (ก - ฮ), จำนวนพยางค์ (1, 2, 3, 4+ พยางค์)
   - เลือกหมวดหมู่ความหมาย: ความสำเร็จ, ความรัก, ความฉลาด/ปัญญา, ความมั่งคั่ง, ความสุข, สุขภาพ, เกียรติยศ, ความเจริญก้าวหน้า
   - ระบบคัดกรองชื่อที่ **"ไร้อักษรกาลกิณี"** และจัดกลุ่มอักษร บริวาร, อายุ, เดช, ศรี, มูละ, อุตสาหะ, มนตรี

2. **ฐานข้อมูลชื่อเริ่มต้น 200 รายชื่อภาษาไทยแท้:**
   - 100 ชื่อเด็กผู้ชาย และ 100 ชื่อเด็กผู้หญิง
   - ระบุคำอ่าน, ความหมายที่ถูกต้อง, รากศัพท์บาลี-สันสกฤต, จำนวนพยางค์, ราศีที่สมพงศ์ และเหตุผลตามทักษา
   - ฟังก์ชันออกเสียงคำอ่านภาษาไทยด้วย Web Speech API
   - ฟังก์ชันคัดลอกชื่อและความหมายลง Clipboard

3. **ระบบสุ่มชื่อเด็กมงคล (Lucky Draw):**
   - วงล้อสุ่มชื่อเด็กที่ไร้อักษรกาลกิณีตามวันเกิดที่ระบุ

4. **ระบบเปรียบเทียบชื่อเด็ก (Name Comparison):**
   - ตารางเปรียบเทียบคุณสมบัติชื่อแบบเคียงข้างกัน (Side-by-Side) สูงสุด 4 ชื่อ

5. **ระบบสมาชิก (Member System):**
   - สมัครสมาชิกและออกรหัส **Member ID** อัตโนมัติ (เช่น `GNO-M000001`)
   - ระบบบันทึกชื่อที่ชื่นชอบ (Favorites) พร้อมเขียนบันทึกส่วนตัวของครอบครัว
   - บันทึกประวัติการค้นหาชื่อ (Search History) พร้อมปุ่มค้นหาซ้ำ
   - แก้ไขข้อมูลส่วนตัว วันกำหนดคลอด และไอคอนโปรไฟล์
   - ระบบลืมรหัสผ่านและรีเซ็ตรหัสผ่าน

6. **ระบบแอดมินและแดชบอร์ดหลังบ้าน (Admin Dashboard):**
   - เข้าสู่ระบบด้วย Admin ID (เช่น `GNO-A000001`)
   - ภาพรวมระบบและกราฟสถิติรายวัน รายเดือน (Pure SVG Data Charts)
   - จัดการสมาชิก (ระงับ / ปลดระงับ)
   - จัดการฐานข้อมูลชื่อเด็ก (CRUD เพิ่ม, แก้ไข, ลบ)
   - ส่งออกและนำเข้าข้อมูล CSV (CSV Export / Import)
   - ปรับแต่งตารางอักษรมงคลและกาลกิณีประจำวันเกิดทั้ง 8 วันได้จากหน้าเว็บ
   - ปรับแต่งข้อมูล 12 ราศีเกิด
   - รายงานและสถิติหมวดหมู่
   - ระบบบันทึกการทำงานของแอดมิน (Admin Logs)

## 🛠️ โครงสร้างฐานข้อมูล (Database Collections)

ออกแบบตามมาตรฐาน Cloud Firestore:
- `users`: ข้อมูลผู้ใช้งาน Member ID, บทบาท (`member` หรือ `admin`), วันที่สมัคร
- `baby_names`: ข้อมูลชื่อ 200 รายชื่อ พร้อมความหมายและหลักทักษา
- `favorites`: รายชื่อที่สมาชิกบันทึกไว้ พร้อมโน้ตส่วนตัว
- `search_history`: ประวัติการค้นหาของสมาชิกแต่ละคน
- `zodiac_signs`: ข้อมูล 12 ราศี ธาตุ และดาวครองเรือน
- `auspicious_letters`: ตารางอักษรมงคล 8 วันเกิดตามทักษาปกรณ์
- `admin_logs`: บันทึกกิจกรรมของผู้ดูแลระบบ
- `system_settings`: การตั้งค่าเว็บไซต์และ Firebase Config

## 🔥 การเชื่อมต่อ Firebase (Cloud Firestore & Auth)

ระบบทำงานแบบ **Hybrid**:
1. ใช้งานได้ทันที 100% ผ่าน Local Persistent Storage ไม่ต้องตั้งค่าเพิ่มเติม
2. หากต้องการเชื่อมต่อ Cloud Firestore ของคุณเอง:
   - เข้าสู่ระบบด้วยบัญชีแอดมิน
   - ไปที่เมนู **ตั้งค่าระบบ & Firebase** ในแดชบอร์ดแอดมิน
   - ระบุ `Firebase Project ID` และ `API Key`
   - กดปุ่ม **"ทดสอบการเชื่อมต่อ Firestore"** ระบบจะตรวจสอบสถานะและเชื่อมต่อไปยัง Firestore ทันที
